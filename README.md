# 讯栈

讯栈是一个本地 Telegram 工作台：可以登录最多 50 个账号，把同一条消息轮流发到这些账号已经加入的群和频道，也可以在本窗口里上下浏览已经加入的频道。

它不会自动加群，也不会给私聊发消息。账号按顺序轮流发言，每条消息之间至少间隔 8 秒。每个账号单次最多 20 个群，一整轮最多 60 个群。这是为了把群发留在你自己负责的群里。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

PC 窗口：

```bash
npm run desktop
```

会打开一个桌面窗口。如果 43127 上已经有开发服务，窗口直接连过去；否则由窗口自己把服务拉起来。登录数据仍在项目里的 `data/` 目录。

## 桌面软件

开发窗口依赖源码目录。要拿出能单独运行的程序：

```bash
npm run package
```

完成后运行：

```bash
./dist/linux-unpacked/xunzhan
```

这是打包好的 Linux 程序，自带页面服务，不需要再开 `npm run dev`。登录会话写在系统的用户配置目录里，不写进安装目录。关掉窗口，里面的服务会一起停。

还没有 Telegram 应用凭证时，可以先点「先用演示数据走一遍」，把选群、间隔和停止发送走通。演示数据不会连接 Telegram。

## 登录真实账号

1. 打开 [my.telegram.org](https://my.telegram.org)，用手机号登录。
2. 进入 API development tools，创建一个应用，拿到 `api_id` 和 `api_hash`。
3. 在讯栈的「应用凭证」里保存这两项。
4. 添加账号。手机号要带国家码，例如 `+8613800138000`。
5. 填入 Telegram 发来的验证码。如果账号开了两步验证，再填一次密码。

也可以用环境变量，不必写进页面：

```bash
TELEGRAM_API_ID=123456
TELEGRAM_API_HASH=your_api_hash
npm run dev
```

登录会话和凭证保存在 `data/`。这个目录相当于已经登录的客户端，不要提交，也不要把这台服务暴露到公网。

## 发送

选中一个或多个账号里的群，写下消息，确认这些群允许你发布，然后开始发送。顺序是每个账号先发一条，再换下一个账号；全部轮过一遍，才发各自的下一条。每条之间都等待设定的间隔。发送过程中可以停止，还没发出去的群会被跳过。

「定时开始」留空就马上发。填了时间后，到点才开始轮流发送，最远 7 天。定时停在当前这次运行里，关掉窗口或重启服务会取消还没开始的那一轮。

真实账号如果遇到 Telegram 的频率限制或群里的慢速模式，这一条会记为失败，其余群继续。

## 浏览频道

切到「浏览」，点一个已经加入的频道。讯栈用历史记录把最近的帖子列在窗口里，然后可以自动上下滑动这个列表。滑动只发生在本窗口，不会标记已读，也不会增加频道阅读数。已经退出的频道不能打开。
