# Storage bot

一个单独的 Telegram 存储机器人。它不属于讯栈，也不转发消息。贴上 @BotFather 的令牌之后，它接收文件，确认并写上名称，然后给出一个口令和一条链接。

只是来存文件的人不用安装。在 Telegram 里打开机器人即可。运行机器人的这台电脑要一直开着。

## 运行

需要 [Node.js](https://nodejs.org/) 20.9 或更新的版本。

```bash
npm install
npm start
```

浏览器打开 http://127.0.0.1:43128 ，把 @BotFather 的 `/newbot` 令牌贴进去，点「开始接收」。

令牌和文件索引写在本机 `data/vault.json`。不要提交 `data/`，也不要把这个页面暴露到公网。

## 在 Telegram 里

底部是四个按钮：获取、首页、存储、管理文件夹。

1. 点「存储」，选新建文件夹，或追加到最近 7 天内的文件夹。
2. 先建好文件夹，再发文件。底部是「取消并退出」和「确认」。
3. 点「确认」，发一个至少 5 个字符的名称。名称发出去就完成，并显示口令和分享链接。

取回时，图片、视频和文件按 10 个一组发出。管理文件夹里可以追加、改名称、查看或删除。

把机器人拉进群之后，群里出现已经打包的口令时，它会回复一条带按钮的链接，一分钟内删掉这条回复。群里要能看见普通消息，需要在 @BotFather 里对这个机器人发送 `/setprivacy`，选 Disable，或者把机器人设成群管理员。
