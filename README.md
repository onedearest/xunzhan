# Storage bot

一个单独的 Telegram 存储机器人。它不属于讯栈，也不转发消息。贴上 @BotFather 的令牌之后，它接收文件，确认并写上名称，然后给出一个口令和一条链接。

只是来存文件的人不用安装。在 Telegram 里打开机器人即可。运行机器人的这台电脑要一直开着。

## 运行

需要 [Node.js](https://nodejs.org/) 20.9 或更新的版本。

```bash
npm install
npm start
```

浏览器打开 http://127.0.0.1:43128 ，把 @BotFather 的 `/newbot` 令牌贴进去，点「接入这个机器人」。

同一台电脑最多接入 10000 个机器人。再贴一个新令牌，会另外收那个机器人的消息，不会停掉已经在收的。每个人的文件夹分开存在 `data/bots/`。不要提交 `data/`，也不要把这个页面暴露到公网。

发给别人的步骤在 `教程.md`。对方只在 Telegram 里做自己的机器人，把令牌私发过来。

## 重启

窗口关掉，或者云电脑重启之后，机器人会停。文件夹还在 `data/` 里，不要删这个文件夹。

1. 如果上次那个窗口还开着，先在里面按 `Ctrl+C`，停掉旧的。同一份程序只留一个窗口。
2. 进入安装时的文件夹，重新启动：

```bash
cd ~/storage-bot
npm start
```

3. 浏览器打开 http://127.0.0.1:43128 。上面写着「正在接收」，已经接过的令牌不用再贴。
4. 这个窗口要一直开着。

要换成最新代码时，先 `Ctrl+C`，再执行：

```bash
cd ~/storage-bot
git pull
npm install
npm start
```

页面上如果出现「这个令牌正在别的地方收消息」，说明还有一份旧程序在跑。把所有正在运行的窗口都停掉，只再执行一次 `npm start`。

要接很多机器人时，把这台电脑允许同时打开的文件数调到 20000 以上。

## 在 Telegram 里

底部是四个按钮：获取、首页、存储、管理文件夹。

1. 点「存储」，选新建文件夹，或追加到最近 7 天内的文件夹。
2. 先建好文件夹，再发文件。底部是「取消并退出」和「确认」。
3. 点「确认」，发一个至少 5 个字符的名称。名称发出去就完成，并显示口令和分享链接。点「口令」按钮，Telegram 会把口令复制下来。

取回时，图片、视频和文件按 10 个一组发出。管理文件夹里可以追加、改名称、查看或删除。

创建者拥有这个机器人，可以存储。其他用户必须由创建者添加 Telegram 用户编号之后，才能存储。私聊机器人发送 /start，回复里有自己的用户编号。打开 http://127.0.0.1:43128，先保存创建者编号，再添加其他可存储的用户编号。没有被添加的人只能用口令取回。

创建者点「首页」看到运营数据：已存文件、用户、下发次数。会员和账户余额目前是 0。普通用户点「首页」看到另一段说明，创建者点「设置用户首页文案」后把广告发过去就能换掉。发送「清空」恢复默认。

把机器人拉进群，或者拉进频道评论所在的讨论群之后，群里或评论区出现已经打包的口令时，它会回复发口令的那条消息。回复里有打开链接，也有按钮。一分钟内删掉这条回复。群管理员开了匿名时，口令同样会回复。

群里要能看见普通消息，需要把机器人设成这个群的管理员，或者在 @BotFather 里对这个机器人发送 `/setprivacy`，选 Disable，然后把机器人移出群再拉进来。设成频道管理员不够，评论在讨论群里。先在群里发 `/start`：有「请私聊我」说明机器人在线；再发口令仍没有回复，看运行窗口有没有「群消息」这几个字。没有这行，就是 Telegram 还没把普通消息送过来。
